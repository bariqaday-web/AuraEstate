# AuraEstate — Luxury Real Estate & Smart Living

Premium responsive landing page template for modern real estate, smart living, and eco-friendly property platforms.

## Included

- White, mint-green, and dark slate luxury visual system
- Hero with property search filter UI
- Full-width featured estate visual
- Three property cards with investment details
- Investment metrics and private investor testimonials
- Interactive virtual-tour presentation frame
- Consultation lead form with budget selection
- Responsive mobile and desktop layouts
- Semantic HTML5 and Tailwind CSS via CDN

## Run locally

```bash
python3 -m http.server 4175
```

Open `http://localhost:4175`.

## Customize

- Replace the CSS property-art placeholders with licensed property photography.
- Update listing names, locations, pricing, metrics, and yield figures.
- Connect the consultation form to your CRM, REST API, Supabase, Firebase, or custom backend.
- Replace the virtual tour button with a video or 3D-tour URL.
- Add real App/CRM analytics without changing the visual structure.

The template is frontend-only; form submissions and property data require your chosen backend integration.
